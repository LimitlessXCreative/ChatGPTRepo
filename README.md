# ChatGPTRepo — NZT-48 3D transfer

Private transfer home for the NZT-48 website, 3D assets and saved Codex conversation.

The complete project, original chat archive and Mac restore helpers are being uploaded as a transfer release. The package contains its own Git history and verified session restore utility.

Open **Releases** for the transfer download and Mac instructions. Git does not automatically synchronize a live Codex chat. The saved session must be restored on the destination Mac, then checked before retiring the source computer.

Do not make this repository public: the archive contains private conversation history.
